### 付款软件显示已扣款，页面仍显示待支付怎么办？

先把付款时间和回执留好，再回原订单确认状态有没有更新。若持续显示待支付，可以从查单页找到客服入口，提供订单号和付款时间请客服核对。此时最重要的是对上原来的交易，先把付款结果确认清楚再决定下一步。

「已出卡」说明买卡订单里的卡密已经发放。已经有充值任务的话，要查看任务是否完成，可以去充值进度查询找那一笔记录。任务显示完成后，再以自己 ChatGPT 账号实际显示的套餐为准。

充值进度查询支持卡密或任务单号。找到匹配的任务后，可以查看对应套餐、处理状态和页面展示的执行记录。如果你保存了任务单号，反馈问题时提供这个编号，会更容易定位到具体记录。

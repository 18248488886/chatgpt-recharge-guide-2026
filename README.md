## 常见问题 FAQ

### 代充下单前，哪些信息值得先确认？

确认服务方、购买的套餐和周期、支付金额、怎么收卡，以及异常订单去哪里查。已有订阅的用户，可以再核对一下原渠道是否还在自动续费。套餐价格和适用条件以购买时的页面为准。

### 卡密、订单查询密码和任务单号有什么区别？

卡密是订单发放的商品信息。查询密码用于在 GPTPay 找回买卡订单，任务单号用来找一笔已提交的充值记录。卡密和查询密码留给自己保管，和客服核对时可以先提供订单号或任务单号。

### 一般怎么看到账时间，可以续费吗？

付款确认后会自动发卡，实际的充值进度以该任务的状态为准。打算续费的话，先看当前方案何时结束、原渠道有没有待确认的续费记录，以及当期商品的适用条件。保留原订单，后面查起来也方便。

### 付款后没找到卡密，或者任务失败怎么办？

扣款后页面关闭，可以回到「买卡订单查询」查看对应订单。已有充值任务的，可以先看是否仍在处理，或是否显示「失败已退回卡密」。显示结果一直有出入时，保留原订单号、任务单号和付款时间，请客服按原记录核对。

### GPTPay 的买卡订单支持哪些付款方式？

买卡页面显示支持微信支付和支付宝。付款前看清金额和套餐，付款后可以从对应订单核对发卡情况。实际可用方式以该笔订单的结算页面为准。

### 报销或开票有什么需要提前确认？

有报销要求的话，付款前先向客服确认这款商品能提供什么凭证，以及开票条件、抬头和项目是否符合你的要求。订单页和支付平台的付款记录也可以留存，方便核对金额与付款时间。

### Grok、Claude 的订阅可以按同一笔订单处理吗？
